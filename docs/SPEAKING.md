# 원어민처럼 말하기 — 말하기 시스템 설계 (v1.33)

> 요청: "현재 저의 수준에서 이 앱으로만 원어민 수준의 영어를 구사할 수 있는 것을 목표로, 부족한 점을 찾아 보완하고 없는 부분은 벤치마크하여 생성해 주세요."

## 1. 진단 — 무엇이 부족했나

코드 6영역 독해와 외부 벤치마크 4갈래(제2언어 습득 연구, Speak·ELSA·Pimsleur·Glossika 등 말하기 앱, 한국어 화자 특화 연구, 브라우저·Whisper 기술 가능성)로 확인한 v1.32의 실제 상태:

| 영역 | v1.32 | 원어민 말하기에 필요한 것 |
|---|---|---|
| 하루 발화량(집중 모드) | 최대 6문장(드라마 따라 말하기 0~1 + 회화 5턴), 전부 선택 | 하루 20~35문장, 매 단계가 입을 여는 구조 |
| 복습 | 100% 고르기(인식형) | 한국어만 보고 영어로 말하기(산출형 회상) |
| 발음 피드백 | 집중 모드에서 0 — 진단·최소대립쌍·내 소리 듣기가 전부 숨긴 화면에만 | 매 발화에 단어별 정오·한국인 혼동축·리듬, 내 소리 vs 원어민 |
| 유창성 | 측정 안 함 | 말 속도·멈춤·반응 지연, 같은 이야기를 점점 짧게 다시 말하기(4/3/2) |
| 채점 신뢰도 | 목표 문장을 받아쓰기 힌트로 넘겨 점수가 부풀었다 | 힌트 없이 받아쓰고, 무음·불명확·스피커 되울림은 채점 전에 거른다 |
| 회화 | 큰 오류만 글로 교정, 다시 말하지 않음 | 교정된 문장을 반드시 다시 말하기, 리액션·되묻기, 한국어식 표현 교정 |
| 성장 가시화 | 녹음을 즉시 버림 | 기준선·월간 같은 질문 녹음으로 '그때 나 vs 지금' |

## 2. 벤치마크에서 가져온 원리

- **산출 + 반복 + 자동화**: 청크(정형 표현)를 말로 꺼내고, 같은 과제를 시간을 줄여 반복(4/3/2)하면 유창성이 오른다.
- **산출형 간격 회상**: 보고 고르는 것보다 떠올려 말하는 회상이 말하기로 전이된다(Pimsleur의 응답 유도).
- **교정 → 다시 말하기**: 교정을 읽기만 하면 남지 않는다. 바로 다시 말하게 한다(Speak·Praktika).
- **이해 가능성 우선 발음**: 한국어 화자에게 기능 부하가 큰 소리(어말 자음·R/L·F/P·V/B·모음 길이)부터, 고변이 음성 식별(HVPT, 여러 목소리)로 귀를 먼저 연다.
- **연음·축약은 따로 가르친다**: gonna·wanna·플랩 T·연음은 들어 본 적이 없으면 알아듣지 못한다.

## 3. 매일 루프 — 전과 후

**전(v1.32)**: 드라마 한 편을 듣고 고르기 → (가끔) 한 줄 따라 말하기 → 회화 5턴.

**후(v1.33, 표준일 12~15분, 상한 20분)**:
1. **홈**: 불꽃 옆 '발화 n/목표'. 보기만 하면 불꽃이 반만 켜진다. 목표는 첫 14일 10 → 20 → 달성 연속 7일마다 +5(상한 35).
2. **에피소드 = 역할극**: 태오의 대사와 지정된 상대 대사(화당 5~6줄)를 내가 말한다. 영어 1.5초 반짝 → 한국어만 보고 말하기 → 단어별 초록/빨강 + 칩 1개(혼동축 > 리듬 > 말 속도) + 내 소리 ▶ / 태오 ▶. 60점 미만이면 영어를 보고 한 번 더, 10단어 이상은 끝부터 쌓기.
3. **엔딩 기본 카드**: 방금 틀린 문장 재소환 → 줄거리 다시 말하기(첫 14일 '3문장 20초', 이후 45/30/20초) → 한국어만 보고 표현 떠올려 말하기.
4. **'조금 더 ▾'**: 리텔 2·3회차(한 줄 교정 포함), 소리 카드 하루 1장(약한 소리 축이 있으면 HVPT, 없으면 소리 디코더), 오늘 질문(월·수·금 20초), D+1·D+4·D+7 고정 문장 녹음.
5. **회화 탭**: 인물과 5턴 + 리액션 한마디(2초) + 교정되면 그 문장을 인물 목소리로 듣고 다시 말하기 + 막히면 🎙 길게 눌러 한국어 → 영어 힌트 + 화·금은 내 문장을 원어민 문장으로 3단 다듬기.
6. **단어 탭**: 상자 2·4 단어는 고르기 대신 예문 말하기. 콩글리시 10·숫자 표현 10 팩 추가.
7. **하루 조절기**: '오늘은 5분만'·조용히 모드(입모양)·복귀 첫날(가볍게, 연속 유지)·힘든 날 자동 감속, 예산 바.
8. **진도 → 말하기**: 녹음 아카이브, 같은 문장 처음 vs 지금, 정확히 말한 단어·말 속도·배운 표현 써먹기 추세, 월 1회 같은 질문 1분 녹음.

## 4. 키가 없어도(그리고 iOS에서도)

모든 말하기 단계는 Groq 키 없이 동작한다. 브라우저 받아쓰기가 있으면 그것으로 채점하고, 없으면(iOS 설치형 앱) 녹음만 해서 **내 소리 ▶ / 원어민 ▶** 비교 + 스스로 확인 ✓로 진행한다. 스스로 확인은 발화 수에는 들어가지만, 점수·레벨·듣기 증거에는 쓰지 않는다. 받아쓰기가 계속 막히면(무음·서버 바쁨·오프라인) 2회 뒤 '스스로 확인하고 넘어가기' 출구가 열린다 — 막다른 화면이 없다.

## 5. 측정의 정직성

- **억양 점수는 매기지 않는다.** 브라우저와 Whisper만으로는 믿을 만한 억양 채점이 불가능하다. 틀린 진단은 진단이 없는 것보다 나쁘다.
- 채점 경로는 **목표 문장을 받아쓰기 힌트로 넘기지 않는다**(인물 이름 6개만). 무음 환각·불명확·스피커 되울림·서버 바쁨은 채점 전에 거른다.
- 지표는 **본인 추세**만 본다(회수율·말 속도·반응 지연·배운 표현 사용). 월 1회 녹음을 힌트 없이 다시 받아쓴 값이 '알아듣기 쉬움'이다.
- 목표 문구는 '원어민과 구분 불가'가 아니라 **'억양은 남아도 원어민 청크·리듬으로 즉시 이해되는 말(C1)'**이다.

## 6. 로드맵

| 단계 | 기간 | CEFR(말하기) | 마일스톤 |
|---|---|---|---|
| 입 트기 | 0~30일 | A1→A2 | 하루 발화 20+(15일차~), 회상 1차 통과 70%, 반응 지연 4→2.5초 |
| 자동화 | 30~90일 | A2→B1 | 목표 30, 교정 재발화 80%, 회화당 리액션 3+, 리텔 분당 90단어 |
| 원어민 결 | 90~180일 | B1→B2 | 리텔 105, 반응 1.5초, 자막 없이 알아들은 대사 70% |
| 즉흥·확장 | 180~365일 | B2 | 군말 턴당 1회 미만, 12개월 녹음 아카이브 |
| C1 | 1~2.5년 | B2→C1 | 분당 130단어+, 월간 알아듣기 쉬움 95%+ |

한국어 L1 화자의 가이드 학습 시간(1.5배 보정)으로 진도 화면에 '다음 레벨까지 약 N시간'을 솔직하게 보여 준다.

## 7. 무료 한도 안에서

Groq 무료 한도(Orpheus 음성 10회/분·100회/일, Whisper 20회/분)를 지키기 위해:
- 합성 음성은 IndexedDB에 영구 캐시(최근 300개)한다.
- 한도에 걸리면 Retry-After 동안 Groq를 부르지 않고 즉시 기기 음성으로 간다(줄마다 기다리지 않는다).
- HVPT 합성은 6초 간격으로 순차 요청한다.
