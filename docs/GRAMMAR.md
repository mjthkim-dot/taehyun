# 문법 시뮬레이션 (v1.27.0)

> "구조만 바뀌고 안의 콘텐츠는 동일하다. 문법적인 사고는 학습할 수가 없다.
> 각 레벨별 문법 학습 사고를 기르기 위한 상황을 실전 시뮬레이션으로."

## 무엇이 새로운가
기존 콘텐츠는 **표현(문장)을 외우는** 구조였다 — 패턴 40개, 미션 표현, 단어. 왜 그 형태인지,
다른 상황에서 어떻게 바꿔 쓰는지는 가르치지 않았다. 문법 시뮬레이션은 **형태를 고르는 이유**를
훈련한다.

## 커리큘럼 — 18유닛, 모두 IT 영업 실전 상황

## 한 유닛 = 5단계 (약 8분)
1. **사고** — 상황 제시 → 질문("왜 과거형(had)을 쓸까?") → **한국어식 사고 vs 영어식 사고** 비교 → 규칙 → 예문 2개(듣기)
2. **판단** 3문항 — 이 상황에 맞는 형태 + 틀리면 *왜* 틀렸는지
3. **조립** 2문항 — 한국어 문장을 영어 어순으로 단어 조각을 눌러 세움. 헷갈리는 오답 조각 포함(tried vs try, has vs have)
4. **실전** 4턴 — 상대 역할(화난 CTO, 구매 총괄, CFO…)과 대화: 고르기 → 조립 → 고르기 → **자유 작문**
   (AI가 목표 문법 관점으로 채점·교정. 키가 없으면 모범 답안과 자기 점검)
5. **결과** — 점수와 틀린 이유 목록. 80점 이상이면 마스터

## 연결
- **오늘의 레슨 2단계 = 문법**(복습 → **문법** → 말하기 → 실전). 현재 CEFR 레벨의 80점 미만 유닛부터,
  레벨을 다 끝내면 다음 레벨로. 누르면 그 유닛이 바로 열리고, 완주하면 단계가 자동 완료
- 더보기 › 학습 › 문법 시뮬레이션(집중 모드에서도 노출) — 레벨 탭(A1~C1, 마스터 수) + 유닛 목록
- 학습 지도(온톨로지)에 레벨별 문법 트랙 + 상황 연결
