## P0 — 실제 미팅에 들고 들어갈 수 있는 최소 세로 절단면

목표: **영어 발언이 들어오면 → 한국어로 이해하고 → 내 자료에 근거한 영어 문장을 받아 말한다.**

### 범위
1. **컴팩트 사이드 패널 PWA** — 폭 360~420px, 설치 가능, 다크 테마
2. **Web Speech STT** — continuous 모드, **interim/final 시각 구분**,
   final 문장 → Claude API 한국어 번역(구어체·미팅 맥락)
2b. **롤링 요약 배너** — 최근 10발화 버퍼, 3문장 누적 또는 30초마다
   "현재 논의 주제 한 줄" 갱신. 번역·요약은 별도 큐, 중복 호출 방지
3. **RAG 검색** — SQLite 벡터 스토어, 하이브리드(키워드+임베딩), 근거 표시
4. **인제스트** — 3종 소스를 넣는 경로 (파일 붙여넣기 + 시드 용어집)
5. **발언 제안** — 검색 결과를 근거로 영어 문장 2안 + 한국어 번역
6. **LLM 다중 공급자 전환** — `interview-coach/backend/llm.py` 계승
7. **세션 아카이브** — 종료 시 트랜스크립트를 RAG 소스로 자동 적재
8. **개인 코퍼스 인덱싱** — Notion 수업 노트를 [표현 / 예문 / 교정받은 문장] 단위로
   청킹·색인. 도메인 용어집 시드 50+개(`data/domain-corpus.json`).
   **갱신은 수동 '동기화' 버튼과 미팅 종료 훅에서만 — 자동 백그라운드 색인 없음**
9. **퀵 리액션 4버튼 + RAG** — 동의/반박/질문/제안. 클릭 → 맥락 5문장으로 top-3 검색 →
   프롬프트 주입 → 15단어 이내·비즈니스 톤 2안 생성 → 검색된 표현을 실제로 썼으면
   "📚 수업에서 배운 표현" 뱃지. 검색이 빈약하면 RAG 없이 폴백.
   하단 한→영 퀵 번역도 **같은 파이프라인**을 탄다

### 수용 기준
| # | 기준 | 측정 방법 |
|---|---|---|
| A1 | 영어 발화 → 자막 표시 | 브라우저에서 말했을 때 화면에 나타남 |
| A2 | 자막 아래 한국어 번역이 채워짐 | 3단어 이상 상대 발화 100%에 번역 존재. (G 개정: 예산 여유 시 final 후 2초, 배칭 시 배치 확정 후 3초 — 대기 4초 포함 최대 7초) |
| A3 | 발언 제안이 **검색된 근거를 포함** | 카드 하단에 출처 청크 제목이 1개 이상 표시 |
| A4 | 제안 지연 ≤ 1.5초 (Cerebras/Groq 기준) | 발화 종료 → 첫 문장 표시까지 자동 측정 |
| A5 | **한국어 노트가 영어 발언에 매칭됨** | 한국어 노트 10건 색인 후, 영어 질의 10건 중 8건 이상이 의도한 노트를 top-3에 포함 |
| A6 | Ollama 없이도 검색 동작 | 임베딩 비활성 상태에서 키워드 경로만으로 A5의 6/10 이상 |
| A7 | LLM 1곳이 죽어도 제안 계속 | 첫 공급자 403 주입 시 다음 공급자로 자동 전환 |
| A8 | 실패가 조용하지 않음 | LLM 429/503/네트워크 단절 주입 시 화면에 원인 표시 |
| A9 | 30분 분량 부하에서 누수 없음 | 발화 60건 주입 후 JS 힙 증가 < 25MB, 큐 잔량 0 |
| A10 | CORS 미개방 | 외부 Origin 요청이 403 |
| A11 | interim/final 구분 | interim은 점선·반투명·"인식 중" 라벨, 확정과 혼동 불가 |
| A12 | 번역 중복 호출 방지 | 같은 문장 3회 → **API 1회**, 단 **표시는 3개 모두** |
| A13 | 요약 갱신 규칙 | 3문장 누적 시 1회 · 30초 타이머 동작 · 내용 무변화 시 호출 0 |
| A14 | 요약 호출 합류 | 연속 9발화(조건 3회) → 요약 3회 이하 (쌓이지 않음) |
| A15 | 수업 노트가 표현 단위로 쪼개짐 | 실제 노트 1건 투입 → [표현/교정/예문]으로 분류된 청크 생성 |
| A16 | 자동 색인 없음 | 앱 기동·미팅 중 어느 시점에도 색인 쓰기가 일어나지 않음. 갱신은 동기화 버튼 / 미팅 종료 훅뿐 |
| A17 | 시드 용어집 50개 이상 | `domain-corpus.json`이 색인에 반영, 시드가 늘면 차집합만 보충 |
| A18 | 4버튼이 전부 RAG를 탐 | 각 버튼 클릭 시 근거 출처가 1개 이상 표시 |
| A19 | 제안 15단어 이내 | 생성된 EN 문장 전부가 15단어 이하 |
| A20 | 📚 뱃지는 **실제로 쓰였을 때만** | 검색만 된 경우 뱃지 없음 · 검색 표현의 3어절 이상이 생성문에 나타나면 뱃지 |
| A21 | 한국어 퀵 번역이 내 노트를 찾음 | 한국어 입력 4건 중 4건이 의도한 수업 노트를 top-3에 포함 (임베딩 없이) |

## P1 — 오디오 설정을 없애고, 쓸수록 좋아지게

### 범위
1. **탭 오디오 캡처** (`getDisplayMedia`) — Zoom Web/Meet 탭 소리를 직접 캡처.
   BlackHole 등 가상 오디오 장치 설정 불필요
2. **화자 구분** — 탭 오디오(상대) vs 마이크(나)를 물리적으로 분리
3. **용어집 자동 성장** — 트랜스크립트에서 반복되는 도메인 용어를 추출해 후보로 제시,
   사용자가 승인하면 용어집에 승격
4. **Notion 노트 인제스트 개선** — 마크다운 내보내기 파일을 통째로 넣으면 블록 단위로 청킹
5. **미팅 사후 요약** — 논의 요점 · 내가 한 약속 · 후속 액션 · 다음에 쓸 표현
6. **복습 자산화** — 트랜스크립트에서 유용 표현 10개 + 못 알아들었을 구간 + 질문 리스트를
   추출해 SRS 카드(1일 / 3일 / 7일)로 저장.
   **Notion 기록은 사용자가 확인 버튼을 누른 것만 — 자동 쓰기 기본 OFF**

### 수용 기준
| # | 기준 | 측정 방법 |
|---|---|---|
| B1 | 오디오 설정 0으로 상대 소리 인식 | 탭 공유만으로 캡처 시작 ✅ (Web Speech는 MediaStream을 못 받으므로 VAD→Whisper 경로) |
| B2 | 상대/나 발화가 구분되어 기록됨 | 트랜스크립트에 화자 레이블 정확도 100%(물리 분리이므로) |
| B3 | 용어 후보 추출 | 2단으로 측정한다 — **통계 재현율**: 60분 분량에서 핵심 도메인 용어 8/10 포착 ✅ · **판별 정밀도**: LLM 판별 후 오탐 30% 이하(mock 기준 0%) ✅. 최종 개수는 실제 모델 판단에 좌우되므로 개수를 기준으로 두지 않는다 |
| B4 | Notion md 파일 인제스트 | 파일 1개 투입 → 블록 단위 청크 생성, 색인 반영 |
| B5 | 사후 요약에 액션 아이템 포함 | 약속/후속 조치가 목록으로 분리되어 표시 |
| B6 | 복습 표현 10개 추출 | 트랜스크립트 1건 → 표현 10 · 놓친 구간 2~5 · 질문 3~5 |
| B7 | SRS 간격 1/3/7일 | 맞힘 → 1→3→7일로 전진, 틀림 → 1일로 복귀, 3회 통과 시 졸업 |
| B8 | Notion 자동 쓰기 없음 | `confirm` 없는 저장 요청은 400으로 거부 |
| B9 | 검색 회귀 테스트 | `tests/rag-eval.ts` 10케이스 중 8건 이상 top-3 적중 |
| B10 | 모바일 390px · Lighthouse | 390×844에서 레이아웃 정상 · 4개 카테고리 90점 이상 |

## P2 — 자동화와 학습 루프

### 범위
1. **Notion 양방향 동기화** — API로 수업 노트를 주기적으로 가져오고, 미팅에서 새로 배운
   표현을 노트로 되돌려 씀
2. **말투 학습** — 내 과거 발화에서 문장 길이·자주 쓰는 연결어를 추출해 제안 문장에 반영
   ("내가 실제로 말할 법한" 정도를 높임)
3. **학습 앱 연동** — 미팅에서 막혔던 표현을 `next-app`(영어 학습 PWA)의 드릴로 넘김
4. **다국어 확장** — 일본어 등 (구조는 동일, 임베딩 모델만 교체)

### 수용 기준
| # | 기준 | 측정 방법 |
|---|---|---|
| C1 | Notion 동기화 | 노트 수정 → 재색인 → 검색 결과에 반영 |
| C2 | 말투 반영 | 제안 문장의 평균 길이가 내 과거 발화 분포의 ±30% 이내 |
| C3 | 학습 앱 핸드오프 | 막힌 표현이 드릴 항목으로 생성됨 |
