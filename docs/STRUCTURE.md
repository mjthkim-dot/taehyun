# 앱 구조 재정비 — "주니어스러움" 걷어내기 (v1.25.0)

> "스픽, 링글을 썼을 때보다 짜임새가 주니어스러운 것 같아요."

## 진단 — 무엇이 주니어스럽게 보였나
홈 한 화면에 **13개 블록**이 쌓여 있었다.

| 문제 | 실제 모습 |
|---|---|
| 주 행동이 4개 | "12주 프로그램 다음 블록" · "오늘 세션 시작" · "오늘의 미션" · "오늘의 훈련 시작" — 무엇부터 누를지 앱이 정해주지 않음 |
| 같은 숫자가 3번 | 오늘 발화 수가 불꽃 카드·링 카드·퀘스트에 각각 |
| 레벨 체계가 2개 | CEFR 카드와 "성숙도 1~5단계" 카드가 나란히 — 무엇이 진짜 내 레벨인지 모호 |
| 이름과 다른 버튼 | "숙제 도우미"·"암기 카드"·"4대 영역"·"내 표현장" 4개 버튼이 전부 같은 '기능' 목록으로 이동 |
| 설명이 UI를 대신함 | "레벨은 증거로만 오릅니다 — …", "기능을 고르는 대신 프로그램을 따라갑니다" 같은 해명 문구 |
| 개발자 용어 | 코어·산출·입증·증거·GSE가 첫 화면에 |
| 더보기 11개 평면 나열 | 성격이 다른 화면(리포트·레슨·면접·피드백)이 한 줄에 |

Speak·Ringle의 공통점은 **목표 → 오늘의 레슨 1개 → 기록**이라는 뼈대가 먼저 보이고,
누를 버튼이 하나라는 것.

## 바뀐 구조

**홈(오늘의 학습)** — 섹션 제목이 뼈대를 만든다
1. 날짜 + "오늘의 학습"
2. **내 레벨**(압축): A2 메달 · B1까지 % · 4기능 칩 · 다음 레벨 과제(보조 버튼)
3. **오늘의 레슨**(유일한 주 버튼): `Unit 1/12 · Lesson 4/5` · 제목 · 4단계 스텝(복습 → 핵심 표현 → 말하기 → 실전) · "레슨 시작"
4. 오늘 기록 — 스트릭·발화 한 카드
5. 실전 상황 — 오늘의 비즈니스 미션
6. 이어서 하기
7. 레벨별 레슨 — CEFR A1~C2 경로
8. 자유 연습 — 빠른 드릴 · 전체 학습 도구

→ 첫 화면(390px)에 레벨 + 오늘의 레슨 + 시작 버튼이 모두 보인다.

**옮긴 것**: 성숙도 카드 → CEFR 리포트의 "원어민 표현 단계", 데일리 퀘스트 → 진도 화면,
중복 링 카드·가짜 버튼 4개·배치고사 안내(레벨 카드와 중복) 삭제.

**용어**: 워밍업/코어/산출 → 복습/핵심 표현/말하기, 서약 → 목표 한 줄, 12주 트레이닝 프로그램 → 12주 코스.

**더보기**: 내 성장(CEFR 리포트·진도·학습 지도) / 학습(레슨·복습·영상) / 실전(실전 코스·면접·비즈니스) / 그 밖에(기능·피드백).

## 집중 모드 (v1.26.0)

> "기능이 너무 많아서 뭐부터 해야 할지 모르겠어요. 선택과 집중이 필요할 것 같아요."

신규 사용자의 **기본값**. 앱을 세 가지로 줄인다.
1. **레벨 진단**(5분, 한 번)
2. **오늘의 레슨**(매일 — 복습·단어 → 핵심 표현 → 말하기 → 실전)
3. 그 밖의 모든 것은 **"모든 기능 보기"** 뒤로

- 홈: 시작 가이드(1 레벨 진단 → 2 12주 코스 시작 → 3 첫 레슨 완료)가 지금 할 단계 하나만
  버튼으로 보여준다. 단계를 마쳐야 다음 카드가 나타나고, 첫 레슨을 마치면 가이드는 사라진다.
- 레벨 카드의 '다음 레벨 과제' 버튼은 숨김 — 오늘의 레슨이 이미 다음 레벨 기준(i+1)이다.
- 하단 탭 4개(홈·단어·회화·더보기), 더보기엔 CEFR 리포트·진도만 + "모든 기능 보기".
- 모든 기능 ↔ 집중 모드 전환은 홈 하단·더보기에서, 선택은 저장된다(`va_mode`).
