## 5. 자동 갱신 루프 (v1.4.0)

1장의 수동 실사를 앱 안의 파이프라인으로 옮겼다 — 코스는 스냅숏이 아니라 루프다.

```
[🔄 지금 재분석] 또는 60일 경과 시 "갱신 추천" 배지
  → 서버: in:sent 90d 스레드 150개 id + 최근 45개 메타데이터 → 상대 도메인 클러스터 집계 (?mode=analyze)
  → 클라이언트: 상위 4개 클러스터의 대표 스레드 본문 → Groq 구조화
      (트랙 자동 분류 · 약점 주입(weaknessBrief) · 원문 해시 캐시 = 같은 분기 재실행 비용 0)
  → 트랙에 🆕 시나리오로 편입 (va_course_extra, 재방문 유지)
```

- 기반 18편(수동 실사 품질)은 고정, 자동 갱신분은 그 위에 쌓인다
- 부분 성공 우선: 클러스터 하나가 실패해도 나머지는 살린다
- 실시간 신규 문서는 실전 영어 탭(Notion·Gmail 루프)이 담당 — 코스(반복 패턴)와 루프(최신 사건)의 역할 분담
- 가드 테스트: `53-courseloop.mjs` 10항목
