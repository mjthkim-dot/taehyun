## 3. 벤치마크 — 카테고리 표준 대비

> ⚠️ **"Smooth.ai"라는 이름의 제품은 검색으로 확인되지 않았다.** 동일 카테고리
> (실시간 면접 코파일럿)의 공개 수치로 벤치마크한다. 특정 제품의 내부 구조는
> 공개돼 있지 않으므로 **지연 수치만** 비교 대상으로 삼는다.

| 기준 | 카테고리 | 우리(실측) |
|---|---|---|
| 좋은 코파일럿의 전체 루프 | 800~1,500ms | — |
| 체감 지연 시작선 | 1,500ms 초과 | — |
| 나쁜 축 | 3,000ms 이상 | — |
| 최상위 사례(Interview Lift) | Zoom 약 700ms | — |
| **우리: 첫 읽을 문장까지** | | **1.34~2.14s** (추정 포함) |
| 우리: 본답변 EN 완결 | | 1.49s (요청 기준) |

**우리 수치 산출**: STT 확정 ~0.3s(**추정** — 브라우저 Web Speech, 샌드박스에서
실측 불가) + 턴 정착 250~1,100ms + 오프너 0.79s.

### 벤치마크가 알려주는 것

1. **우리는 카테고리 하단~중간이다.** 최상위(700ms)와의 격차는 모델 속도가
   아니라 **턴 정착 대기(최대 1,100ms)** 에서 온다. 이것이 지금 **가장 큰
   제어 가능 항목**이다.
2. **그러나 정착 대기를 그냥 줄이면 v5.0으로 되돌아간다.** 짧게 잡으면 말하는
   중에 발사돼 조각마다 재생성이 일어난다(그때 질문 1개에 8회 발사).
3. **Tier A(조회)가 이 딜레마를 푼다.** 조회는 LLM 토큰을 쓰지 않으므로
   **틀린 조기 발사가 공짜다.** 400ms에 한 번 조회해 띄우고, 턴이 끝나면
   교체하면 된다. 즉 Tier A는 정확도 장치일 뿐 아니라 **지연 장치**다.

## 6. 착수 전 확인 4가지

1. **다음 면접 일정.** 1주일 이내면 **Phase 0+1만**(1.5일) 하고 멈춘다.
   면접 직전에 라우팅 구조를 바꾸는 것은 위험하다.
2. **KR·PR을 실제로 보는가.** 안 본다면 분리가 아니라 **삭제**가 맞다
   (호출 수도 안 늘고 1.5초를 회수한다).
3. **답변 유닛을 그대로 읽을 것인가, 참고만 할 것인가.** Tier A의 품질 기준과
   작업량이 여기서 갈린다.
4. **다음 면접 대상 회사.** 유닛 승격 30~40건 선정 기준.

§1의 등급 판정 중 이견이 있으면 지적해 달라 — 근거를 다시 대겠다.
