한국인 IT 영업 실무자를 위한 **실시간 영어 미팅 보조 + 개인화 RAG**.

차별점은 하나다 — **내 자료를 검색해서, 내가 실제로 말할 법한 문장을 만든다.**
범용 번역기는 "문법적으로 맞는 문장"을 주지만, 이 앱은 내 수업 노트에서 배운 표현과
내 지난 미팅의 말투, 그리고 내 업계 용어로 문장을 만든다.

- 설계와 근거: [../docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md)
- 단계별 계획과 수용 기준: [../docs/PLAN.md](../docs/PLAN.md)

## 실행

```bash
export GEMINI_API_KEY=...             # 기본 공급자 — aistudio.google.com/apikey (무료)
bash meeting-copilot/start.sh         # 기동 요약 4줄(로드·콜드스타트·공급자·잔여 한도) 출력
# → http://localhost:3799/app.html
# 실전 당일 아침: bash meeting-copilot/preflight.sh  (30초 판정)
```

### 세 가지 배포 모드 (같은 코드, 다른 설정)

| 모드 | 인증 | 언제 |
|---|---|---|
| 로컬 개인 | 없음 | 내 노트북에서 (기본) |
| 개인용 웹 | 로그인 | 폰·회사 PC 어디서든 — TLS 프록시 뒤에서 |
| 다중 사용자 | 사용자별 계정 + **물리적으로 분리된 데이터** + LLM 쿼터 | 지인·팀 |

인증은 사용자를 만드는 순간 켜진다(`python3 manage.py adduser 이름 --admin`).
사용자가 없는 상태로 외부 인터페이스에 바인딩하면 **서버가 기동을 거부한다** —
무인증 공개 실수를 막기 위해서다. 웹 배포 절차·운영·백업은
[../docs/DEPLOY.md](../docs/DEPLOY.md).

키가 막히거나 없으면 `Cerebras → Groq → Gemini → Ollama` 순으로 자동 전환된다
(`export CEREBRAS_API_KEY=csk-...` 등을 함께 넣어두면 보험이 된다).

**모델은 경로마다 다르게 쓴다** — 자막 번역·한 줄 요약은 지연이 곧 품질이라
빠른 모델(`ANTHROPIC_FAST_MODEL`, 기본 Haiku 4.5), 발언 제안은 품질이 우선이라
`ANTHROPIC_MODEL`(기본 Sonnet 5)을 쓴다. 둘 다 환경변수로 바꿀 수 있다.

의존성 설치가 없다. 파이썬 표준 라이브러리만 쓴다.
**미팅 화면 옆에 창을 좁게 두고** 쓰는 것이 기본 사용법이다 (폭 360~420px 기준 설계).

### 의미 검색 켜기 (선택, 무료)

```bash
ollama pull bge-m3
```

한국어로 쓴 수업 노트를 **영어 발언으로 검색**할 수 있게 된다.
없어도 동작한다 — 키워드만으로도 쓸 만하게 설계했다(자료에 영문 검색어를 함께 심는다).

## 무엇이 뜨는가

| 상대가 말하면 | 화면 |
|---|---|
| 말하는 중 | **점선 버블 + "인식 중" 라벨** (확정 자막과 혼동되지 않게) |
| 문장이 끝나면 | 확정 자막 + 그 아래 **구어체 한국어 번역** |
| 질문·반론·요구 | **발언 제안 카드** — 영어 2안 + 한국어 + 전략 + 📎 근거 |
| 3문장 또는 30초마다 | 상단 배너에 **"지금 무슨 주제인지"** 한 줄 |

말할 차례엔 **동의 · 반박 · 질문 · 제안** 네 버튼 중 하나를 누른다.
누르면 [직전 발화 + 맥락 5문장]으로 내 자료를 검색해 top-3을 프롬프트에 넣고,
**15단어 이내** 영어 2안을 만든다. 검색된 표현을 실제로 썼으면
**📚 수업에서 배운 표현** 뱃지가 붙는다 (검색만 됐다고 붙지 않는다 —
뱃지에 마우스를 올리면 어떤 표현이 근거인지 보인다).
하단의 한→영 입력창도 **같은 파이프라인**을 탄다.

### 호출 규율

미팅 1시간이면 발화가 수백 건이라, 그대로 흘리면 한도와 지연이 함께 무너진다.

- **번역**: 레인 2개 병렬. 같은 문장은 **API를 한 번만** 부르고 결과를 캐시해 재사용한다
  (되묻기처럼 같은 말이 두 번 나와도 자막은 두 번 다 채워진다)
- **요약**: 최근 10발화만 보고, 진행 중에 조건이 또 걸리면 쌓지 않고 끝난 뒤 1회만 재실행.
  내용이 그대로면 호출 자체를 건너뛴다

카드의 **📎 근거**는 어느 자료에서 나온 문장인지 보여준다. 지어낸 문장이 아님을 확인할 수 있고,
근거가 비면 "자료를 더 넣어달라"고 알려준다.

### 발언 차례 감지

면접과 달리 미팅은 물음표가 없어도 답해야 하는 순간이 많다.
`"Your quote is higher than the other vendor"` 처럼 **반론·우려·요구·결정 신호**도 감지한다
(실측: 답해야 할 발화 10/10 감지, 맞장구 오탐 0/7).

### 단축키

| 키 | 동작 |
|---|---|
| `Space` | 카드 고정/해제 (읽는 중 새 발언이 덮지 않게) |
| `Esc` | 카드 닫기 |
| `+` / `-` | 제안 글자 크기 (100/118/140%) |

## 내 자료 넣기 (RAG)

'자료' 탭에서:

1. **Notion 수업 노트** — 페이지 주소를 넣거나(`NOTION_TOKEN` 필요) 내용을 붙여넣으면
   **[표현 / 예문 / 교정받은 문장]** 단위로 쪼개 색인한다
2. **미팅 트랜스크립트** — ⏹ 로 세션을 끝내면 **자동 적재**. 쓸수록 내 말투가 쌓인다
3. **도메인 용어집** — 클라우드/AWS 세일즈 표현 **70개** 기본 탑재
   (`backend/data/domain-corpus.json`), JSON으로 추가 가능

### 색인은 언제 갱신되나

**자동 백그라운드 색인을 하지 않는다.** 내 노트를 앱이 몰래 읽어가는 일이 없도록,
갱신은 세 지점에서만 일어난다:

| 시점 | 무엇이 |
|---|---|
| '자료' 탭의 **🔄 지금 동기화** | 용어집 시드 보충 + 등록해 둔 Notion 페이지 당겨오기 + 임베딩 누락분 채우기 |
| **⏹ 미팅 종료** | 트랜스크립트 적재 + 복습 카드 생성 |
| 인제스트 버튼을 직접 누를 때 | 붙여넣은 노트 / 용어 JSON |

기동 시 시드 적재도 네트워크를 타지 않는다(임베딩은 동기화 때 채운다).

용어집에는 `triggers`(고객이 실제로 하는 말)를 함께 적는 게 핵심이다.
`"quote is higher"` 라는 발언이 `total cost of ownership`을 꺼내오려면 그 다리가 필요하다.

```json
[{"term":"egress cost","ko":"데이터 전송 비용",
  "note":"예상 못한 비용의 주범","say":"Let's model egress up front.",
  "triggers":"hidden cost unexpected charges surprise bill data transfer"}]
```

## 미팅이 끝나면 — 복습 자산화

⏹ 를 누르면 요약·적재와 함께 **복습 탭**이 채워진다.

- **유용 표현 10개** — 이번 미팅에서 쓸 만했던 문장 + 한국어 뜻
- **놓쳤을 구간** — 빠른 축약·관용구·숫자처럼 못 알아들었을 법한 부분을 원문 그대로
- **다음에 물어볼 질문** — 이번에 열린 채로 남은 쟁점에서

표현은 **간단 SRS 카드**가 된다. 맞히면 1일 → 3일 → 7일로 간격이 벌어지고,
세 번 통과하면 졸업한다. 틀리면 1일로 되돌아간다.

> **Notion 기록은 기본 꺼져 있다.** 저장할 페이지를 직접 넣고 버튼을 눌러
> 확인한 것만 기록된다 (`NOTION_TOKEN`이 없으면 '마크다운 복사'로 붙여넣으면 된다).

## 자기 강화 루프

```
미팅 진행 → ⏹ 종료 → 요약 + 트랜스크립트가 자료로 적재 + 복습 카드
                              ↓
                     다음 미팅에서 검색됨 → 내 말투로 제안
```

## 프라이버시

- 트랜스크립트는 **맥북 안 SQLite에만** 저장 (`backend/data/store.db`, 커밋 차단)
- CORS를 열지 않는다 — 다른 사이트가 미팅 기록을 읽지 못한다
- 기본 바인딩은 `127.0.0.1`
